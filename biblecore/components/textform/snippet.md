- **Following sibling** of the verse, same rules as `.gloss` and `aside.echo`: never nested, always closed, `data-anchor` = the verse it follows.
- `data-src` = the witness: `mt`, `lxx`, `sp` (Samaritan), `dss` (Qumran), `qere`, `ketiv`, `targum`, `peshitta`, `vulgate`. Site prints the label: start the text with what the witness reads or lacks.
- One aside per witness per verse, one line. Which reading is earlier → footnote.
- Transliterate or translate. Never Greek or Hebrew script.

**Verified =** the witness itself checked (edition, apparatus, or the commentary on hand that cites it), not a secondhand summary. Say which source in a footnote when it matters.
