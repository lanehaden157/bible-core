```html
<aside class="textform" data-anchor="1:4" data-src="lxx">lacks “the whole land of the Hittites.”</aside>
```

- It's a **following sibling** of the verse, like `.gloss` and `aside.echo`, with the same rules: never nested, always closed, and `data-anchor` is the verse it follows.
- `data-src` names the witness: `mt`, `lxx`, `sp` (Samaritan), `dss` (Qumran), `qere`, `ketiv`, `targum`, `peshitta`, `vulgate`. The site prints the label, so start the text with what the witness reads or lacks.
- One aside per witness per verse. Keep it to a line, and put the argument about which reading is earlier in a footnote.
- Transliterate or translate. Never type Greek or Hebrew script.

**What counts as verified:** you've checked the witness itself (an edition, an apparatus, or the commentary on hand that cites it), not a secondhand summary. Say in a footnote which source it came from when it matters.
