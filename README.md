# bible-core

The shared architecture for new books in the Bible study platform: a small
pinned package, a starter template each book owns, and shared wording
defaults. Not used by Joshua or Matthew, which are the reference
implementations.

- `ARCHITECTURE.md`: the shared shape, where books differ, and how the core
  changes.
- `canon/conventions.md`: shared wording defaults that each book's glossary
  starts from.

Plan and status: `../g6-plan.md`. Session notes live one level up, in the
`Bible/` session files.
