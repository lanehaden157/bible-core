# Canon Conventions

Vendored from bible-core as `canon-conventions.md`; don't edit book's copy.
Shared wording defaults: one English word for one thing across books.
**Defaults, not rules.** A book's `translation-choices.md` starts here and
records only its own decisions, any deviation from a row + the reason.
Changing a row changes no shipped unit, only the starting point for books
that haven't chosen yet.

## Register (every book)

| convention | default | note |
|---|---|---|
| second-person plural | **y'all**, possessive **y'all's**. Singular "you" unmarked. | |
| divine name | **Yahweh**, always. Transliterate `YHWH` (Hebrew). Greek *kyrios* standing for the name → Yahweh. | |
| sky | **sky / skies**, always: *shamayim*, *ouranos*, *ouranios*. | Cosmological senses too: one fixed rendering beats a per-verse call. |
| slave | **slave**, not "servant": *ʿeved*, *doulos*. "Slave of Yahweh" for Moses' title. | |
| life / being | **life** (singular), **being(s)** (plural): *nefesh*, *psychē*. | One exception, **person**: *nefesh* as generic distributive singular in legal or battle formulae ("kills a person"). |
| look | **look**, not "behold": *idou*, *hinneh* | |
| amen | **amen**, transliterated, not "truly" | |

## Settled across books

A book may depart from any of these if it records the change and reason in its
style reference. Check before proposing a canon thread or type-scene.

- Studies cite English (KJV) verse numbering. Word table and reading text keep
  the corpus's own.
- Canon threads: inheritance, rest, fear, torah, tassels, charge. A book's
  thread slugs are never renamed to match; the canon thread maps to them.
- Type-scene ids: commissioning, scouts, water-crossing, census,
  mountain-theophany, annunciation. A new id needs a label.
- Transliteration schemes are frozen per language, never harmonised across
  languages.
- Each book's unit map comes from its own project side.
- A book's declined thread candidates live in its `data/roots.json`
  `declined{}`.
