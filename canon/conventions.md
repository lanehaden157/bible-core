# Canon Conventions

Shared wording defaults, so that a reader moving between books meets one
English word for one thing. **These are defaults, not rules.** A book's
`translation-choices.md` starts from this file and records only what it
decides for itself, including any deviation from a row here and the reason.

Every row cites where it was decided. Joshua and Matthew keep their own
glossaries as they are; this file collects what they already agree on.

Changing a row here doesn't change any shipped unit. It changes the starting
point for books that haven't made the choice yet.

## Register (every book)

| convention | default | source |
|---|---|---|
| second-person plural | **y'all**, and possessive **y'all's**. Singular "you" is left unmarked. | Matthew 2026-09-12; Joshua 2026-09-16, possessives 2026-09-22 |
| divine name | **Yahweh**. Never "LORD" or "the Lord". Transliterate as `YHWH` (Hebrew). Greek *kyrios* standing for the name is rendered Yahweh. | both |
| sky | **sky / skies**, never "heaven(s)": *shamayim*, *ouranos*, *ouranios*. This applies in cosmological senses too, because a fixed rule beats a per-verse call re-argued in every book. | Matthew; Joshua 2026-09-19 (C12) |
| slave | **slave**, not "servant": *ʿeved*, *doulos*. "Slave of Yahweh" for Moses' title. | Matthew; Joshua 2026-09-19 (C10) |
| life / being | **life** (singular) and **being(s)** (plural), never "soul": *nefesh*, *psychē*. There is one documented exception, **person**, where *nefesh* is a generic distributive singular in legal or battle formulae ("kills a person"). | Matthew; Joshua 2026-09-21 |
| look | **look**, not "behold": *idou*, *hinneh* | Matthew 2026-09-12; Joshua units 2–4 already use "look" throughout |
| amen | **amen**, transliterated, not "truly" | Matthew |

## Hebrew Bible vocabulary

| word | default | source / note |
|---|---|---|
| ʾaron | **chest** (not "ark"); "chest of the covenant", "chest of the testimony" | Joshua 2026-09-22. Numbers has it often (10:33–36, 14:44). |
| berit | **covenant** | Joshua 2026-09-22 |
| ḥaram / ḥerem | verb **devote(d) to destruction**. The noun is contextual ("designated for destruction", "the ban"). | Joshua 2026-09-21. Numbers 21:2–3 (Hormah) is an early hit. |
| naḥalah | **inheritance**; the causative is "give as an inheritance" | Joshua 2026-09-16. Numbers 26–27, 32–36 are heavy. |
| qadash / qodesh | "set apart" for the reflexive/consecrate sense ("set yourselves apart"), "holy" for the adjective and the noun ("holy ground") | Joshua 2026-09-22 (the `holy` thread). **Numbers will stress this.** Expect the book to refine it. |
| Yam Suf | **Reed Sea** | Joshua 2026-09-21 |
| torah | left untranslated ("torah"), glossed | Joshua |
| ḥesed | **left untranslated ("ḥesed")**, glossed at first occurrence in each unit | Joshua 2026-09-21; made the Hebrew Bible default 2026-09-22 (Lane). Matthew's "loyal-love" for Greek *eleos* is unaffected. |

These rows matter only for Greek books. They are Matthew's settled choices,
offered as defaults.

| word | default |
|---|---|

| kyrios (of Jesus or a human) | **Master**, not "Lord" |
| baptizō / baptistēs | **immerse / Immerser** |
| mathētēs | **learner**, not "disciple" |
| pistis / pisteuō | **trust**, not "faith" or "believe" |

| hypokritēs | **stage-actors** |
